# Employee-Crud-springboot
Employee Management System is a backend web application built with Spring Boot that allows users to manage employee records efficiently. The project implements Create, Read, Update, and Delete (CRUD) operations through RESTful APIs and uses Spring Data JPA, Hibernate, and MySQL for data persistence. The application follows a layered architecture with Controller, Service, Repository, and Entity components, ensuring maintainability and scalability.

Technologies Used
Java
Spring Boot
Spring Data JPA
Hibernate
MySQL
Maven
REST API
